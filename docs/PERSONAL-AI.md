# 누리원 개인 AI 비서

개인 업무 화면에서 AI 비서를 열어 OpenAI API, Anthropic API 또는 Gemini API를 선택합니다. 승인된 각 계정의 API 키는 개인 연결 설정에서 입력합니다. 키는 서버에서 암호화하며 저장 후 화면에 다시 표시하지 않습니다. 모델 호출은 로그인한 사용자가 제출한 요청과 해당 사용자가 연결한 공식 API 계정으로 실행합니다.

일반 채팅은 답변을 스트리밍합니다. 일정 요약을 선택하면 내 일정과 할 일만 현재 답변의 문맥으로 제공합니다. 할 일, 개인 일정, 메모, SNS와 메일 초안, 카드뉴스는 해당 작업을 선택했을 때 내 업무 공간에 저장합니다. 게시와 발송은 원고를 검토하고 개인 예약 화면에서 별도로 승인합니다. 카드뉴스는 개인 파일로 미리보고 다운로드할 수 있습니다. Instagram 또는 Threads 초안에 첨부해 예약을 승인하면 실제 발행 때 이미지 주소가 발급됩니다.
