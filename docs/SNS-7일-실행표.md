## 4. Instagram v2 이미지 검수 메모

실제로 이미지를 Read로 보고 판단했다(리드도 별도로 열어 구성·문장 일치를 재확인). 색값은 측정하지 못했고 대비는 화면 눈대중이다. sns-growth.md에는 이 이미지에 대한 설명이 없고(제천대성의 벽 예시 문장은 출처 미확인이라 창작 문장으로 새로 쓴다는 주의 문장만 있음), 이 메모가 그 설명을 대신한다.

- **구성:** 1122×1402px(약 4:5, 리드가 PNG 헤더로 측정) 세로 이미지. 업로드 시 1080×1350 리사이즈 여부는 Codex가 확인한다. 상단 좌측에 검정 굵은 고딕 3줄("좋아."만 주황 계열로 더 크게), 우측에 거대한 어두운 돌벽, 중앙 하단에 주황 작업복·흰 운동화 원숭이가 망치로 금 간 자리의 X 표시를 가리킨다. 배경은 오프화이트.
- **좋은 점:** 문장이 그림과 일치한다(금, X, 망치). 표정에 유머가 있다. 텍스트가 3줄로 짧아 첫 진입이 빠르고 빈 공간이 충분하다. 글자 높이가 커서 폭 390px로 줄여도 읽힐 것으로 보인다(눈대중으로 마지막 줄도 약 20px 이상).
- **확인할 점:**
  1. 1:1 중앙 크롭이 되는 그리드에서는 첫 줄 상단이 일부 잘릴 수 있다. 실제 프로필 그리드에서 확인한다.
  2. "좋아."의 주황 글자와 배경의 대비는 약 3.5~4:1로 추정한다. 큰 글자 3:1 기준은 통과로 추정되지만 실제 색값으로 측정해야 한다.
  3. 원숭이 캐릭터가 알려진 캐릭터와 닮았는지는 육안으로는 구별되지만(황금 머리띠·여의봉 없음) 권리 판단은 아니다. 특정 작품·인물의 캐릭터로 소개하지 않고 실제 유사성 검수를 거친다.
  4. 생성 도구로 만든 이미지라면 플랫폼의 AI 표시 요건을 게시 화면에서 확인한다.
  5. 320·390px 폭 축소 화면, 피드와 그리드 크롭, 문구 맞춤법을 실제 렌더로 확인한다.

## 5. 티스토리 비교: 노출 있는 오래된 글 갱신 vs 새 검색 문제해결 글

근거는 sns-growth.md에 이미 기록된 공개 근거로 한정했다(50행: 유입이 있는 글에서도 제목 연도 불일치, 긴 인사, 근거 없는 순위, 빠진 alt, 오래된 조건이 확인됨). 어느 글이 지금 노출 중인지는 모르며 T1에서 Codex가 Search Console로 확인한다. 아래 서열은 가정이며 Search Console 확인 뒤 확정한다.

| 기준 | A 노출 있는 글 갱신 | B 새 문제해결 글 |
|---|---|---|
| 수요 증거 | 이미 노출이 있다는 것 자체가 검색 의도 신호(대상 글은 미확인) | 이 주제의 검색 수요를 확인하지 못함 |
| 작업량 | 제목·조건·alt 수정 중심. 새 글보다 적을 가능성이 높으나 사실 재검증 비용이 있음 | 직접 실행·캡처·공식 확인·작성이 모두 필요해 큼 |
| 사실 검증 부담 | 게임 패치 등은 공식 공지 재확인 필요 | 명령·메뉴를 직접 실행해야 함 |
| 위험 | 제목 변경이 CTR을 떨어뜨릴 수 있음(스냅샷으로 롤백 가능) | 색인·노출이 없을 수 있음 |
| 측정 가능성 | 같은 URL의 28일 전후 비교(계절·순위 변동에 교란됨) | 비교군이 약하고 n=1 |
| 반응 지연 | 노출이 이미 있어 더 빠를 가능성 | 색인과 노출까지 지연 |

결정 규칙:
1. T1에서 노출이 있고 T2에서 오래된 조건·연도 불일치·alt 누락이 확인되는 글이 있으면 A를 먼저 한다.
2. 후보가 없거나 모두 최신이면 B만 진행한다.
3. 둘 다 가능하면 이번 주 일정처럼 A를 먼저 하고 B는 직접 실행·캡처가 끝난 뒤 발행한다.
4. 새 글 B에 쓰는 시간이 길어지면 B는 다음 주로 미룬다. A는 미루지 않는다.
