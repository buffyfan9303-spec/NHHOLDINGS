## 0. 전제와 한계

- 이 클라우드는 게시·계정 설정·운영 DB·과금을 하지 않는다. 표의 실행 담당은 모두 Codex 또는 사용자다. 원고 초안 작성은 이미 끝났다.
- 이 클라우드의 네트워크 정책이 Instagram·Threads·티스토리·Google 개발자 문서·Meta 공식 문서를 막아 원문을 열지 못했다. 이 문서의 근거는 (a) 저장소의 sns-growth.md, (b) 리드가 전달한 검색 요약, (c) 실제로 본 이미지 한 장이다. 마지막의 '원문 검증 필요 목록'은 Codex가 로그인된 브라우저로 확인한다.
- 성장은 보장하지 않는다. 팔로워·조회 구매, 맞팔 품앗이, 다중 계정 조작, 가짜 인용·가짜 경험·가짜 성과, 수익 약속은 하지 않는다.
- 비공개 Search Console·인사이트 수치는 이 문서와 공개 문서에 적지 않는다. 원문은 `.gitignore`된 `artifacts/operations/`에 두고 경로만 남긴다.
- 날짜의 요일은 달력 계산이다. 10/09(금)는 한글날이지만 계정 주제와 무관해 소재로 쓰지 않는다(sns-growth.md: 계정 주제와 무관한 검색량은 사용하지 않음).
- 임계값은 모두 사전 등록용 임의 설정이며 업계 기준이 아니다. 표본이 작아 우열을 확정하지 않고 방향성 메모로 쓴다.

## 5. 티스토리 비교: 노출 있는 오래된 글 갱신 vs 새 검색 문제해결 글

초기 Claude 검토는 sns-growth.md의 공개 근거에 한정됐다. 이후 Codex가 10/08 실제 Search Console의 기간·검색 유형·검색어→페이지를 대조했고 `/155`·`/157` 기존 글 교정을 마쳤다. 이 자료는 수정 전 기간의 본인 사이트 노출이며 전체 검색량이나 수정 후 효과가 아니다. 아래 비교는 일반적인 작업 판단 기준이며, 이미 완료한 글을 새 작업으로 다시 실행하지 않는다.

| 기준 | A 노출 있는 글 갱신 | B 새 문제해결 글 |
|---|---|---|
| 수요 증거 | 이미 노출이 있다는 것 자체가 검색 의도 신호(대상 글은 미확인) | 이 주제의 검색 수요를 확인하지 못함 |
| 작업량 | 제목·조건·alt 수정 중심. 새 글보다 적을 가능성이 높으나 사실 재검증 비용이 있음 | 직접 실행·캡처·공식 확인·작성이 모두 필요해 큼 |
| 사실 검증 부담 | 게임 패치 등은 공식 공지 재확인 필요 | 명령·메뉴를 직접 실행해야 함 |
| 위험 | 제목 변경이 CTR을 떨어뜨릴 수 있음(스냅샷으로 롤백 가능) | 색인·노출이 없을 수 있음 |
| 측정 가능성 | 같은 URL의 28일 전후 비교(계절·순위 변동에 교란됨) | 비교군이 약하고 n=1 |
| 반응 지연 | 노출이 이미 있어 더 빠를 가능성 | 색인과 노출까지 지연 |

결정 규칙:
1. T1에서 노출이 있고 T2에서 오래된 조건·연도 불일치·alt 누락이 확인되는 글이 있으면 A를 먼저 한다.
2. 후보가 없거나 모두 최신이면 B만 진행한다.
3. 둘 다 가능하면 이번 주 일정처럼 A를 먼저 하고 B는 직접 실행·캡처가 끝난 뒤 발행한다.
4. 새 글 B에 쓰는 시간이 길어지면 B는 다음 주로 미룬다. A는 미루지 않는다.
