# NURI ONE 계정 성장 운영 기준

기준일: 2026-10-08, 한국 시간. 첫 목표는 SNS 계정 자체의 성장이다. 누리 서비스 유입·회원 가입·상품 판매를 초기 성과로 강제하지 않는다. 티스토리는 검색형 정보 매체, Instagram·Threads는 사람들이 다시 찾는 콘텐츠 계정으로 각각 운영한다.

## 채널별 편집 방향

| 채널 | 독자가 얻는 것 | 우선 시험할 형식 | 우선 볼 지표 |
|---|---|---|---|
| Instagram | 다시 움직이고 싶은 기분, 친구에게 보내고 싶은 한 장, 저장할 작은 행동 | 자체 제작 캐릭터·창작 문장 한 장 / 구체적인 공감과 반전 / 3~5장 실용 캐러셀 | 비팔로워 도달, 공유·저장, 새 팔로우, 프로필 방문 |

계정은 아무 인기 주제나 뒤섞지 않는다. Instagram은 **다시 움직이게 하는 한 컷과 한 문장**, Threads는 **글만으로 완결되는 관찰과 유머**를 초기 약속으로 잡는다. 동기부여·구체적인 일상 공감·작은 실행을 그 안에서 시험한다. 건강 진단, 투자 추천, 출처 없는 유명인 인용, 타인의 일화로 꾸민 창작은 사용하지 않는다. 모든 글을 질문으로 끝내거나 매번 좋아요·댓글·태그를 요구하지 않는다. 현재 집중 채널은 티스토리·Instagram·Threads이며 X·Shorts·TikTok은 준비 단계다.

Meta는 Threads의 대화·유머·텍스트를 동반한 미디어·플랫폼용 원작을 권고했다. 이는 2024년 공개 후 2025년 갱신된 플랫폼 집계 안내이며 한국의 새 계정에서 특정 형식이 이긴다는 증거는 아니다. Instagram도 원작 추천 정책을 설명하지만 정적 이미지의 저장·공유 가중치 공식은 공개하지 않았다. Shorts는 특정 형식을 우대한다고 설명하지 않고 시청 선택·지속 등과 개인화를 설명한다. 숫자 규격은 플랫폼 성과 공식이 아니라 제작 출발점이다. 티스토리는 본문 17~18px·줄간격 약 1.75·읽기 폭 720~800px를 출발점으로 실제 스킨과 공개 화면에서 조정한다. 모바일은 좌우 16~24px 여백을 확보하고 한 문단이 길어지면 의미 단위로 나눈다. H2 개수·제목 글자 수·FAQ·표 개수를 할당량으로 강제하지 않는다. 표는 필요한 비교에만 쓰고 모바일에서 잘리면 항목을 줄이거나 가로 스크롤을 제공한다. 제목·본문에 같은 키워드를 기계적으로 반복하지 않는다. 이미지 가까이에 설명·alt·확인일/버전이 필요한 캡션을 둔다. 생성 삽화는 설명용으로 구분하며 실제 사용 화면을 꾸미지 않는다. 실제 Search Console의 페이지·검색어를 기간·검색 유형과 함께 읽고 기존 글 원문을 열어 확인했다. 유입이 있는 글도 제목 연도와 발행 시점 불일치, 긴 인사·과장 소개, 근거 없는 순위, 빠진 alt·오래된 조건이 있었다. 유입이 있다는 이유로 그 서식과 주장을 복제하지 않는다. 먼저 검색 의도와 누락을 파악하고 최신 공식 자료로 재검증한다. 본인 계정의 비공개 검색 실적 수치는 이 공개 가이드에 게시하지 않는다. 경쟁 사례에 대한 관찰과 자체 성과 분석, 편집 판단을 구분한다.

기존 @nh_yaho 질문형 Threads 1건은 발행 약 15분 뒤 인사이트에서 조회 5, 조회한 사람 2, 프로필 방문 0, 팔로우 0이었다. 자체 확인 조회가 포함됐을 수 있고 관찰 시간이 짧아 성공·실패를 판정할 수 없다. 이 값을 하루·월간 실적이나 경쟁 계정 순위로 확대하지 않는다.

Google Trends 한국·지난 24시간 화면의 2026-10-08 11:29 갱신값에서 `10 월 9 일` 묶음은 `2천+`, `+1,000%`였고 관련 항목에 한글날·한글이 있었다. 이것은 해당 기간의 대략적인 검색량 구간이며 명언·한글날 각각의 월간 검색량이 아니다. 계정 주제와 무관하면 검색량이 커도 사용하지 않는다. Explore의 0~100 상대 관심도, Trending Now 구간 검색량, Keyword Planner 등의 월간 검색량, Search Console의 우리 사이트 노출을 서로 바꾸지 않는다. ## 발행 전 다섯 가지 검사

1. **최신 트렌드:** 당일 플랫폼과 최근 7일·30일 흐름에서 계정 독자와 관련 있는 후보를 고른다. 출처 URL·지역·기간·확인 시각·선택/제외 이유를 남긴다. 오래된 인기를 최신 유행이라고 쓰지 않는다.
2. **검색 수요:** 실제 제공되는 검색어·수치·범위·기간·지역·도구 이름을 그대로 기록한다. 미확인은 미확인으로 남긴다. 검색량은 검색 의도 판단용이며 SNS 추천 도달 예측값이 아니다.
3. **성과 표본:** 같은 플랫폼·주제·형식·경과시간의 원게시물에서 조회와 공개 반응을 구분한다. 실제 조회가 공개되지 않으면 조회 순위를 만들지 않고 공개 반응 표본을 대체 근거로 표시한다. 정확한 조회 순위는 확인 가능한 우리 게시물부터 쌓는다.
4. **원고:** 첫 줄에 관심 이유가 있고 읽은 뒤 관점·감정·실행 중 하나가 남는지 본다. 맞춤법·띄어쓰기·호응·자연스러운 어투·중복·과장·인용 출처를 직접 확인한다.
5. **이미지·전체:** 모든 장·썸네일·프레임·캡션을 실제 렌더해 잘림·순서·글자·대비·모바일 가독성·alt·권리·계정·시간을 확인한다. 문구와 그림이 서로 보완해야 한다. 한 장이면 한 장으로 완결한다.

실험 원고도 사실과 권리·이미지 검사에는 예외가 없다. 다른 계정의 비공개 조회나 미제공 검색량은 위조하지 않고 한계와 대체 근거를 기록한다. 근거 없는 ‘잘되는 형식’ 확정이나 수익 약속은 하지 않는다. 검색·시각 검수 도구가 없는 생성 API는 초안만 만들며 검수를 수행했다고 표시하지 않는다. 현재 저장 프롬프트는 편집 규칙이며 서버가 모든 검사를 자동 수행·통과시킨다는 뜻이 아니다.

## 첫 2주 실험과 학습

초기 실험량은 플랫폼 의무나 최적 빈도가 아니라 검수·답글·측정을 감당할 가설이다. Instagram은 주 3~4개, Threads는 주 4~5개를 출발점으로 잡는다. 동일 원고의 복제·몰아 올리기는 하지 않는다. 검수와 지표 확인이 가능한 게시만 진행한다. 티스토리의 하루 발행 상한·시간은 별도 발행 운영 설정을 따른다.

| 실험 | 바꾸는 요소 | 비교 기준 |
|---|---|---|
| A 창작 캐릭터 한 장 | 시각적 이야기 + 짧고 힘 있는 문장 | 공유·저장·프로필 방문·새 팔로우 |
| B 구체적인 공감 한 장 | 현실적인 상황 + 예상과 다른 관점 | 공유·실제 경험 답글 |
| C 작은 실행 캐러셀 | 바로 해볼 행동·예시 3~5장 | 저장·공유·새 팔로우 |
| D 짧은 관찰·유머 | Threads용 독립 문장과 자연스러운 대화 | 조회·답글·리포스트·팔로우 |

각 게시에 가설·형식·대상·첫 문장·게시 시각·검수·실제 URL을 남긴다. 게시 후 24시간·72시간·7일 수치를 **게시물별 근거 메모**에 남기고 같은 경과시간끼리 비교한다. 누적 스냅샷을 일별 성과 합계에 반복 입력하지 않는다. 요일·시간 시험은 같은 형식에서 번갈아 진행하며 아직 ‘가장 많이 검색되는 시간’이라고 부르지 않는다.

누리원의 일별 성과는 KST 해당 날짜의 증분이다. 계정 성장 캠페인은 캠페인·날짜·채널당 한 건을 수정해서 쓰며, 누적 팔로워 총수와 게시물 누적 조회를 넣지 않는다. 당일 진행 중이면 근거 메모에 집계 종료 시각을 적고 하루 종료 후 같은 기록을 갱신한다. 계정 전체 수치를 여러 캠페인에 복제하지 않는다. 빈칸은 null/미확인, 확인한 0은 0이다. 부분 합계에는 확인 건수를 표시한다. 도달의 일별 값을 더해 월간 고유 인원으로 해석하지 않는다.

조회는 많고 팔로우가 적으면 계정의 반복 가치와 프로필 약속을, 저장은 많고 공유가 적으면 실용성·공감의 차이를, 프로필 방문은 많은데 팔로우가 적으면 소개와 기존 게시물의 일관성을 점검한다. 비율은 같은 기간·대상·분모를 확보한 경우에만 계산한다. 작은 표본에서는 우열을 확정하지 않고 가설을 수정한다. 주 1회 7일 기준 중앙값·이상치·제작 시간을 함께 보고 반응 없는 템플릿을 중단한다. 플랫폼이 다른 조회 정의를 합쳐 순위를 만들지 않는다.

## 티스토리는 별도 매체로 운영

공개 홈의 카테고리는 GAME 82개(마비노기 모바일 39개 등), PROGRAM 19개처럼 게임·프로그램 축이 크다. 공개 홈 추출은 최근 발행분·동적 화면을 모두 반영하지 않을 수 있으므로 발행 전 관리 화면에서 현재 글·카테고리·중복을 확인한다. [기존 블로그](https://doto1.tistory.com/)

게임은 현재 공식 패치·적용 버전·직접 확인한 단계·실패 조건·스크린샷을, AI·업무 도구는 실제 사용 조건·복사해 쓸 예시·오류 해결·비교를 제공한다. 경험하지 않은 일을 해본 것처럼 쓰지 않는다. 검색 상위 문서를 말만 바꾸어 대량 생성하거나 명언 이미지를 늘려 블로그 분량을 채우지 않는다. 기존 관련 글을 실제 읽은 뒤 내부 링크하고, 갱신일과 출시일을 구분한다. Google의 AI 검색에도 유용하고 독창적인 정보와 검색 기본요건을 적용하며 전용 GEO 태그를 필수로 만들지 않는다. [People-first](https://developers.google.com/search/docs/fundamentals/creating-helpful-content), [생성형 AI 콘텐츠](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content), [AI 검색 기능](https://developers.google.com/search/docs/appearance/ai-features)

Search Console의 우리 사이트 노출·클릭과 GA4 실제 제공 지표를 먼저 보고 28일 단위로 비교한다. AdSense는 실제 계정에 제공되는 페이지뷰·추정/확정 수익·page RPM을 따로 확인한다. RPM은 비교 지표이며 조회수만으로 확정 수익을 만들 수 없다. [Search Console 성능 보고서](https://support.google.com/webmasters/answer/10268906?hl=en), [AdSense RPM](https://support.google.com/adsense/answer/190515?hl=en)

## 수익화는 성장 다음에 자격·실수익 확인

- Instagram: 관련 오디언스가 쌓이면 실제 프로페셔널 대시보드에서 기프트·구독·Creator Marketplace 자격을 확인한다. 한국 출시 발표가 있다는 사실은 현재 이 계정의 활성화나 지급을 뜻하지 않는다. 협찬은 실제 계약과 공개 표시를 갖춘 경우에만 수익으로 기록한다. [한국 기프트·구독 안내](https://about.fb.com/ko/news/2023/12/instagram-gift-subscription-bonus-program/), [한국 Creator Marketplace](https://about.fb.com/ko/news/2024/05/instagram-introduces-creator-marketplace-in-korea/)
- Threads: 이번 조사에서 현재 한국 계정의 직접 지급 자격은 확인하지 못했다. 조회를 자동 현금 수익으로 환산하지 않는다. 초기에는 대화와 팔로워 성장을 평가한다.
- Shorts·TikTok: 명언 정지 화면에 기계 음성만 반복하는 생산보다 자체 스토리·해설·편집을 갖춘 영상이 준비됐을 때 시험한다. Shorts 조회 정의와 참여 조회를 구분한다. 수익 자격·정책은 신청 시 공식 화면에서 다시 확인하며 새 계정·유료 플랜을 자동 생성하지 않는다. [YouTube 수익화 정책](https://support.google.com/youtube/answer/1311392?hl=en), [TikTok 보상 안내](https://support.tiktok.com/en/business-and-creator/creator-rewards-program/creator-rewards-program)

순수익 판단에는 실제 정산 수익에서 제작·도구·API·광고 비용을 뺀 금액과 제작 시간을 사용한다. 무료 노출도 제작 시간이 든다. 조회→수익의 고정 환율·최소 수익을 가정하지 않는다. 유료 광고·크레딧·API 결제는 승인 없이 시작하지 않는다. Facebook·LinkedIn·Pinterest는 현재 운영 채널에 다시 추가하지 않는다.

## 구현·도구·검증 경계

실제 파일은 `public/one/studio.js`(성장·수익 화면), `src/server/dashboard.cjs`(저장 검증), `tests/content-tools.cjs`·`tests/studio-growth.cjs`(회귀 검사)다. 저장된 공통/채널 프롬프트는 기존 `nh_documents`와 반복 실행 경로를 재사용한다. 새 분석 SDK·유료 API·크롤러·플러그인을 설치하지 않았다.

공식 웹 검색과 로그인된 Chrome의 공개 게시물·본인 인사이트 조회, Supabase SQL 읽기·설정 저장 후 대조, 기존 자동화 도구 호출이 성공했다. Chrome 업로드 권한과 이미지 업로드 동작은 확인했지만 Instagram 공개 발행과 Meta API OAuth 연결은 별개의 미완료 항목이다. 설치된 스킬은 content-creation·performance-report·imagegen을 사용했다. 생성 이미지 도구는 사용했으며 서버의 유료 OpenAI API를 켜거나 결제하지 않았다. 커넥터 존재를 인증·실사용 성공으로 표현하지 않는다.

주 에이전트는 UI·프롬프트·통합 검증을 맡았다. GPT-6 Luna medium은 공식 정책·매체 분리 조사, Luna low는 공개 표본 조사와 UI 독립 검토를 맡아 조사 비용을 줄였다. 기존 publication_safety 에이전트는 좁은 서버 입력·중복·금융 분리 검사를 맡았다. 사용자 요청에 따라 로그인된 Claude Max의 Opus·high로 문장·구성·원본 생성 이미지 독립 비평도 실제 수행했다. 검토는 모델 재학습이 아니며 기존 작성 기준과 다음 작업 프롬프트에 반영한다. 검토자의 숫자·권장 규격·표본 해석도 다시 확인하고 임의 규칙은 채택하지 않는다. 수용 기준은 링크 없는 성장 캠페인 저장→재조회→화면 소비, 미확인/0 구분, 일별 중복 차단, 기존 수익·비용·권한 유지, PC/모바일 넘침 없음이다. 배포 SHA·실제 도메인 검증은 작업 결과 기록에서 별도로 남긴다.
