# NURI ONE 계정 성장 운영 기준

기준일: 2026-10-09, 한국 시간. 첫 목표는 SNS 계정 자체의 성장이다. 누리 서비스 유입·회원 가입·상품 판매를 초기 성과로 강제하지 않는다. 티스토리는 검색형 정보 매체, Instagram·Threads는 사람들이 다시 찾는 콘텐츠 계정으로 각각 운영한다. 아래 새 운영량과 Threads 편집 방향은 기존 초기 시험안보다 우선한다.

## 채널별 편집 방향

| 채널 | 독자가 얻는 것 | 우선 시험할 형식 | 우선 볼 지표 |
|---|---|---|---|
| Instagram | 다시 움직이고 싶은 기분, 친구에게 보내고 싶은 한 장, 저장할 작은 행동 | 자체 제작 캐릭터·창작 문장 한 장 / 구체적인 공감과 반전 / 3~5장 실용 캐러셀 | 비팔로워 도달, 공유·저장, 새 팔로우, 프로필 방문 |
| Threads | 돈과 시간을 아낄 수 있는 확인된 정보 | 할인·무료 혜택 / 구독·도구·생활 서비스 사용 팁 / 마감·조건 비교 | 조회, 공유·리포스트, 실제 답글, 팔로우 |
| X | 짧고 선명한 관점과 검증 가능한 정보 | 한 문장 관점 / 이미지 한 장 / 필요한 경우에만 연속 글 | 제공되는 조회·재게시·프로필·팔로우 |
| YouTube Shorts | 처음부터 궁금하고 끝에 보상이 있는 짧은 이야기 | 자체 제작 캐릭터의 작은 사건·반전·해결, 실제 설명과 편집 | 참여 조회, 시청 선택 비율, 유지·완주, 구독 증가 |
| TikTok | 짧은 이야기와 플랫폼에 어울리는 표현 | 권리 확인된 자체 영상이 준비됐을 때만 별도 시험 | 제공되는 시청·완주·공유·팔로우 |
| 티스토리 | 검색한 문제의 해결과 선택 기준 | 게임 공략·패치 적용 / 프로그램·AI 도구 사용 단계 / 직접 만든 체크리스트·비교 도구 | Search Console 노출·클릭·CTR, GA4 제공 지표, 실제 AdSense 수익 |

계정은 아무 인기 주제나 뒤섞지 않는다. Instagram은 **다시 움직이게 하는 한 컷과 한 문장**, Threads는 **돈과 시간을 아껴주는 정보**를 시험한다. Threads의 추상적인 공감·명언·억지 질문은 기본값에서 제외하며 Instagram 캡션을 옮기지 않는다. 할인 정보는 공식 원문과 실제 이용 조건을 확인하고 기간·대상·최소 결제·한도·중복·제외·자동갱신 등 해당 조건을 글 안에서 설명한다. 현재 최저가·무료·마감 임박을 확인 없이 단정하지 않는다. 공식 링크는 확인용으로 필요한 만큼만 쓴다. 제휴·협찬 등 실제 경제적 관계는 명확히 표시하고 미연결 제휴 링크를 자동 삽입하지 않는다. 포스터·상품 사진의 이용권을 확인하지 못하면 복제하지 않고 자체 문장으로 사실을 요약한다. 건강 진단, 투자 추천, 출처 없는 유명인 인용, 타인의 일화로 꾸민 창작은 사용하지 않는다. 모든 글을 질문으로 끝내거나 매번 좋아요·댓글·태그를 요구하지 않는다. 현재 집중 채널은 티스토리·Instagram·Threads이며 X·Shorts·TikTok은 준비 단계다.

Meta는 Threads의 대화·유머·텍스트를 동반한 미디어·플랫폼용 원작을 권고했다. 이는 2024년 공개된 플랫폼 집계 안내이며 한국의 새 계정에서 특정 형식이 이긴다는 증거는 아니다. Instagram도 원작 추천 정책을 설명하지만 정적 이미지의 저장·공유 가중치 공식은 공개하지 않았다. Shorts는 특정 형식을 우대한다고 설명하지 않고 시청 선택·지속 등과 개인화를 설명한다. [Threads 공식 안내](https://about.fb.com/news/2024/10/find-your-community-with-new-threads-educational-insights/), [Instagram 원작 추천](https://about.fb.com/ltam/news/2024/04/ajudando-o-criador-de-conteudo-a-encontrar-novos-publicos/), [Shorts 발견과 추천](https://support.google.com/youtube/answer/11914225?hl=en)

2026-10-08 클라우드 조사에서는 네트워크 정책으로 공식 원문을 열지 못했으나 Codex가 위 Threads 공식 안내와 Meta의 2026년 발표를 별도로 확인했다. ‘2025년 갱신’ 날짜는 확인되지 않아 근거로 사용하지 않는다. Meta는 2025년 4분기 미국 Instagram 추천의 75%가 원작이라고 발표했다. 미국 플랫폼 집계이며 한국의 새 계정 도달이나 특정 카드의 성과를 보장하지 않는다. [Meta 2026년 발표](https://about.fb.com/news/2026/01/2026-ai-drives-performance/)

[캐러셀 사례](https://www.instagram.com/thegoodquote/p/DeLPI97Fy9B/)는 확인한 세 장 모두 흰 바탕·굵은 검정 글자·중앙 정렬을 유지하면서 첫 장보다 뒤의 설명을 늘렸다. 개별 좋아요 합계가 숨겨져 있어 **디자인 참고**이며 해당 디자인의 성과 증거가 아니다. 큰 계정의 팔로워 수를 우리 새 계정의 예상 성과로 바꾸지 않는다. 원문·브랜드·배치 그대로 복제하지 않고 읽기 위계와 밀도만 참고한다.

숫자 규격은 플랫폼 성과 공식이 아니라 제작 출발점이다. Instagram 4:5 작업에서는 좌우 약 8~10% 여백을 시작으로 실제 업로드 미리보기에서 조정한다. 글자는 휴대폰 폭 360~390px로 축소해 읽고 한 단어만 보이는 썸네일·그림 위 묻힌 자막은 수정한다. 손글씨·미니멀 타이포·자체 캐릭터를 후보로 두며 모든 글을 웅장한 생성 그림으로 만들지 않는다. 기존 그림의 문구와 캐릭터를 동시에 바꾼 결과는 복합 콘셉트 탐색으로만 기록한다. 형식의 효과를 비교할 때는 이후 비슷한 주제·문구 길이·시각 조건에서 한 요소만 바꾼다.

티스토리는 본문 17~18px·줄간격 약 1.75·읽기 폭 720~800px를 출발점으로 실제 스킨과 공개 화면에서 조정한다. 모바일은 좌우 16~24px 여백을 확보하고 한 문단이 길어지면 의미 단위로 나눈다. H2 개수·제목 글자 수·FAQ·표 개수를 할당량으로 강제하지 않는다. 표는 필요한 비교에만 쓰고 모바일에서 잘리면 항목을 줄이거나 가로 스크롤을 제공한다. 제목·본문에 같은 키워드를 기계적으로 반복하지 않는다. 이미지 가까이에 설명·alt·확인일/버전이 필요한 캡션을 둔다. 생성 삽화는 설명용으로 구분하며 실제 사용 화면을 꾸미지 않는다. [Google 이미지 안내](https://developers.google.com/search/docs/appearance/google-images)

실제 Search Console의 페이지·검색어를 기간·검색 유형과 함께 읽고 기존 글 원문을 열어 확인했다. 유입이 있는 글도 제목 연도와 발행 시점 불일치, 긴 인사·과장 소개, 근거 없는 순위, 빠진 alt·오래된 조건이 있었다. 유입이 있다는 이유로 그 서식과 주장을 복제하지 않는다. 먼저 검색 의도와 누락을 파악하고 최신 공식 자료로 재검증한다. 본인 계정의 비공개 검색 실적 수치는 이 공개 가이드에 게시하지 않는다. 경쟁 사례에 대한 관찰과 자체 성과 분석, 편집 판단을 구분한다.

기존 @nh_yaho 질문형 Threads 1건은 발행 약 15분 뒤 인사이트에서 조회 5, 조회한 사람 2, 프로필 방문 0, 팔로우 0이었다. 자체 확인 조회가 포함됐을 수 있고 관찰 시간이 짧아 성공·실패를 판정할 수 없다. 이 값을 하루·월간 실적이나 경쟁 계정 순위로 확대하지 않는다.

Google Trends 한국·지난 24시간 화면의 2026-10-08 11:29 갱신값에서 `10 월 9 일` 묶음은 `2천+`, `+1,000%`였고 관련 항목에 한글날·한글이 있었다. 이것은 해당 기간의 대략적인 검색량 구간이며 명언·한글날 각각의 월간 검색량이 아니다. 계정 주제와 무관하면 검색량이 커도 사용하지 않는다. Explore의 0~100 상대 관심도, Trending Now 구간 검색량, Keyword Planner 등의 월간 검색량, Search Console의 우리 사이트 노출을 서로 바꾸지 않는다. ## 발행 전 다섯 가지 검사

1. **최신 트렌드:** 당일 플랫폼과 최근 7일·30일 흐름에서 계정 독자와 관련 있는 후보를 고른다. 출처 URL·지역·기간·확인 시각·선택/제외 이유를 남긴다. 오래된 인기를 최신 유행이라고 쓰지 않는다.
2. **검색 수요:** 실제 제공되는 검색어·수치·범위·기간·지역·도구 이름을 그대로 기록한다. 미확인은 미확인으로 남긴다. 검색량은 검색 의도 판단용이며 SNS 추천 도달 예측값이 아니다.
3. **성과 표본:** 같은 플랫폼·주제·형식·경과시간의 원게시물에서 조회와 공개 반응을 구분한다. 실제 조회가 공개되지 않으면 조회 순위를 만들지 않고 공개 반응 표본을 대체 근거로 표시한다. 정확한 조회 순위는 확인 가능한 우리 게시물부터 쌓는다.
4. **원고:** 첫 줄에 관심 이유가 있고 읽은 뒤 관점·감정·실행 중 하나가 남는지 본다. 맞춤법·띄어쓰기·호응·자연스러운 어투·중복·과장·인용 출처를 직접 확인한다.
5. **이미지·전체:** 모든 장·썸네일·프레임·캡션을 실제 렌더해 잘림·순서·글자·대비·모바일 가독성·alt·권리·계정·시간을 확인한다. 문구와 그림이 서로 보완해야 한다. 한 장이면 한 장으로 완결한다.

실험 원고도 사실과 권리·이미지 검사에는 예외가 없다. 다른 계정의 비공개 조회나 미제공 검색량은 위조하지 않고 한계와 대체 근거를 기록한다. 근거 없는 ‘잘되는 형식’ 확정이나 수익 약속은 하지 않는다. 검색·시각 검수 도구가 없는 생성 API는 초안만 만들며 검수를 수행했다고 표시하지 않는다. 현재 저장 프롬프트는 편집 규칙이며 서버가 모든 검사를 자동 수행·통과시킨다는 뜻이 아니다.

각 게시에 가설·형식·대상·첫 문장·게시 시각·검수·실제 URL을 남긴다. 게시 후 24시간·72시간·7일 수치를 **게시물별 근거 메모**에 남기고 같은 경과시간끼리 비교한다. 누적 스냅샷을 일별 성과 합계에 반복 입력하지 않는다. 요일·시간 시험은 같은 형식에서 번갈아 진행하며 아직 ‘가장 많이 검색되는 시간’이라고 부르지 않는다.

누리원의 일별 성과는 KST 해당 날짜의 증분이다. 계정 성장 캠페인은 캠페인·날짜·채널당 한 건을 수정해서 쓰며, 누적 팔로워 총수와 게시물 누적 조회를 넣지 않는다. 당일 진행 중이면 근거 메모에 집계 종료 시각을 적고 하루 종료 후 같은 기록을 갱신한다. 계정 전체 수치를 여러 캠페인에 복제하지 않는다. 빈칸은 null/미확인, 확인한 0은 0이다. 부분 합계에는 확인 건수를 표시한다. 도달의 일별 값을 더해 월간 고유 인원으로 해석하지 않는다.

`계정 성장 · 수익`의 게시물별 누적 관찰에는 실제 게시 시각·관찰 시각·플랫폼 지표명과 근거를 남긴다. URL 등록 시각을 실제 게시 시각으로 대신하지 않는다. 예측 비교 창은 24시간±2시간, 72시간±6시간, 7일±12시간으로 정한 운영 기준이며 산업 표준이 아니다. 실제 경과 시간도 함께 표시한다. 창 안의 가장 가까운 관찰 한 건으로 비교하며 누적값을 일별 합계·수익·비용에 더하지 않는다.

조회 예상은 운영자 가정 또는 같은 채널·성장 캠페인의 과거 독립 게시물 실측 참고값이다. 실측 모드는 해당 비교 창에서 게시물당 한 관찰만 쓰고 3개 게시물 미만이면 저장을 거절한다. 수동 모드에서 근거를 적고 예상치를 명시적으로 미확인으로 남길 수 있다. 중앙값·관측 범위는 통계적 신뢰구간이나 도달 보장이 아니며, 중앙값 미달을 통계적 실패로 해석하지 않는다. 수익·직접비 예상은 근거를 적은 가정으로 별도 저장하며 실제 월 손익에 합산하지 않는다. 예측은 서버의 최초 저장 시각에 고정하고 수정하지 않는다. 관찰 뒤 예상치를 만들어 사후 성과를 맞추지 않는다.

예상 미달은 재점검의 시작이다. 소재·첫 문장·이미지·가독성·도달과 지표 정의를 실제 원고·화면에서 다시 확인하고 원인 후보와 다음 실험을 구분해 기록한다. 다음 원고에 반영한 개선안은 해당 채널의 AI 초안 작성 기준에 전달된다. 이는 모델 자체의 재학습·자동 사실 검수·게시 성공을 뜻하지 않는다. 후속 비교는 서버의 반영 기록 이후 게시·관찰한 다음 콘텐츠와 원본의 같은 경과 시간 결과를 나란히 표시한다. 한 번의 상승이나 평균 회귀를 효과 입증으로 바꾸지 않고, 이후 동일 조건의 반복 표본으로 유지·중단을 판단한다.

관찰 일정은 실제 게시 시각이 별도로 확인된 게시물에서만 계산한다. 선택한 월의 24시간·72시간·7일 목표와 허용 종료 시각, 예정·관찰 중·기록·누락을 표시한다. 관찰 누락은 조회 0이 아니다. 기록이 있어도 플랫폼이 제공하지 않은 지표는 미확인으로 유지한다. 좋은 글만 골라 기록하지 않고 모든 공개 글의 누락을 함께 점검한다. 실제 게시 시각이 없는 공개 글은 전체 목록의 별도 누락으로 표시하며 월별 확인분 분모에 섞지 않는다. 게시 시각 정정은 이전 관찰을 이력으로 보존하고 기존 예측 비교를 무효화한다. 정정 뒤 사후 예측은 차단한다. 관찰 시각은 최초 저장 후 고정하며 지표·근거 정정도 이전 저장본을 보존한다.

조회는 많고 팔로우가 적으면 계정의 반복 가치와 프로필 약속을, 저장은 많고 공유가 적으면 실용성·공감의 차이를, 프로필 방문은 많은데 팔로우가 적으면 소개와 기존 게시물의 일관성을 점검한다. 비율은 같은 기간·대상·분모를 확보한 경우에만 계산한다. 작은 표본에서는 우열을 확정하지 않고 가설을 수정한다. 주 1회 7일 기준 중앙값·이상치·제작 시간을 함께 보고 반응 없는 템플릿을 중단한다. 플랫폼이 다른 조회 정의를 합쳐 순위를 만들지 않는다.

순수익 판단에는 실제 정산 수익에서 제작·도구·API·광고 비용을 뺀 금액과 제작 시간을 사용한다. 무료 노출도 제작 시간이 든다. 조회→수익의 고정 환율·최소 수익을 가정하지 않는다. 유료 광고·크레딧·API 결제는 승인 없이 시작하지 않는다. Facebook·LinkedIn·Pinterest는 현재 운영 채널에 다시 추가하지 않는다.

## 구현·도구·검증 경계

실제 파일은 `public/one/studio.js`(성장·수익 화면), `src/server/dashboard.cjs`(저장 검증), `tests/content-tools.cjs`·`tests/studio-growth.cjs`(회귀 검사)다. 저장된 공통/채널 프롬프트는 기존 `nh_documents`와 반복 실행 경로를 재사용한다. 새 분석 SDK·유료 API·크롤러·플러그인을 설치하지 않았다.

공식 웹 검색과 로그인된 Chrome의 공개 게시물·본인 인사이트 조회, Supabase SQL 읽기·설정 저장 후 대조, 기존 자동화 도구 호출이 성공했다. Instagram 창작 카드 1건은 Chrome에서 공개 발행 후 실제 URL·본문·이미지·alt·AI 라벨을 확인했다. Meta API OAuth 연결은 별개의 미완료 항목이다. 설치된 스킬은 content-creation·performance-report·imagegen을 사용했다. 생성 이미지 도구는 사용했으며 서버의 유료 OpenAI API를 켜거나 결제하지 않았다. 커넥터 존재를 인증·실사용 성공으로 표현하지 않는다.

캡션에 ‘AI를 활용해 직접 만든 문장과 그림입니다’ 같은 제작 안내를 반복 삽입하지 않는다. 2026-10-08 사용자 의견을 반영해 첫 Instagram 글에서도 해당 문장을 제거하고 공개 화면 재조회를 완료했다. 필요한 AI 고지는 게시 화면의 플랫폼 라벨로 처리한다. 유명인 발언처럼 보이게 꾸미지 않되, 내부 원고의 ‘창작’ 표기를 공개 캡션마다 기계적으로 복사하지 않는다. [Meta AI 표시 안내](https://about.fb.com/news/2024/04/metas-approach-to-labeling-ai-generated-content-and-manipulated-media/)

주 에이전트는 UI·프롬프트·통합 검증을 맡았다. GPT-6 Luna medium은 공식 정책·매체 분리 조사, Luna low는 공개 표본 조사와 UI 독립 검토를 맡아 조사 비용을 줄였다. 기존 publication_safety 에이전트는 좁은 서버 입력·중복·금융 분리 검사를 맡았다. 사용자 요청에 따라 로그인된 Claude Max의 Opus·high로 문장·구성·원본 생성 이미지 독립 비평도 실제 수행했다. 검토는 모델 재학습이 아니며 기존 작성 기준과 다음 작업 프롬프트에 반영한다. 검토자의 숫자·권장 규격·표본 해석도 다시 확인하고 임의 규칙은 채택하지 않는다. 수용 기준은 링크 없는 성장 캠페인 저장→재조회→화면 소비, 미확인/0 구분, 일별 중복 차단, 기존 수익·비용·권한 유지, PC/모바일 넘침 없음이다. 배포 SHA·실제 도메인 검증은 작업 결과 기록에서 별도로 남긴다.
