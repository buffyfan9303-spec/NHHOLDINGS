# SNS 월 운영이익 목표와 실행 기준

기준일: 2026-10-08 KST. 범위는 티스토리 `doto1`과 Instagram·Threads `nh_yaho` 세 계정뿐이다. 새 SNS, 물리 상품 마켓플레이스 판매, 다른 NURI 사이트로의 유입 강제는 목표에서 뺀다. 콘텐츠 편집·근거·게시 전 공통 검수는 [SNS 성장 기준](sns-growth.md)을 따른다.

## 목표와 현재 실적

월 목표는 개인소득세 전 운영이익 **300만원**이다.

`확정된 AdSense·제휴·협찬 수입(플랫폼 수수료 차감 후) − 직접 제작·운영비 = 개인소득세 전 운영이익`

광고 수익은 AdSense 사이트·계정 승인, 한국 지급 자격과 지급 설정을 실제로 확인한 뒤에만 반영한다. 제휴 수익은 승인된 프로그램, 한국 지급 가능 여부, 고유 링크와 발생 전환 정산 내역이 확인되어야 한다. 협찬은 서명된 계약과 이행·정산 근거가 있어야 한다. Instagram·Threads 일반 조회수에는 기본 수입을 붙이지 않는다. 계정 연결·승인·국내 지급을 확인하지 않은 예상액은 목표 실적에 넣지 않는다.

**현재 운영이익: 미확인.** 2026-10-08 KST에 AdSense 읽기 전용 OAuth 연결·명시적 publisher 선택·계정 전체 지급 내역 API 조회와 누리원 새로고침 후 표시를 확인했다. 티스토리의 이번 달 도메인별 보고서는 집계 데이터가 없어 수익·페이지뷰·RPM을 미확인으로 유지했다. AdSense 실제 화면은 초기 설정 완료·광고 게재 가능 여부 검토 중이었다. 연결 완료는 사이트 승인·광고 노출·확정 수익·실입금을 뜻하지 않는다. 계정 전체 지급 내역을 티스토리 수익으로 배분하거나 재무 원장에 자동 합산하지 않는다. 비공개 수치·계정·조회 증거는 `artifacts/operations/`에 보관한다.

## 가정 계산과 예시

Google의 Page RPM은 페이지 조회수 1,000회당 **추정 수익** 지표이며 확정 지급액이 아니다. Google 표시 수익에서 이미 반영된 수익배분 수수료를 다시 차감하지 않는다. 월 직접비를 30만원으로 가정하면 광고로 월 300만원의 이익을 내려면 수수료 차감 후 광고 수익 330만원이 필요하다. 다음은 Page RPM 가정별 산술 역산일 뿐, 트래픽·수익 전망이나 약속이 아니다. 실제 비용은 추가 구독·제작 도구·운영비와 본인 작업 시간을 따로 기록하고 입금 지연도 고려한다.

| 가정 Page RPM | 330만원을 위한 월 페이지뷰 역산 |
|---:|---:|
| 3,000원 | 110만 |
| 5,000원 | 66만 |
| 10,000원 | 33만 |

혼합 예시: 광고 50만원 + 제휴 150만원 + 협찬 130만원 − 직접비 30만원 = 300만원. 수입은 수수료 차감 후라고 가정한다. 이는 계약, 실제 단가, 전망 또는 달성 실적이 아니다. 국내 지급 자격과 정산을 확인하기 전에는 제휴 프로그램을 수입으로 세지 않는다. [Make 제휴 조건](https://help.make.com/affiliate-program)과 [ElevenLabs 제휴 프로그램](https://elevenlabs.io/affiliates)은 검토 후보일 뿐, 가입·승인·국내 지급 가능성은 확인되지 않았다.

## 기록과 증거

일별 게시 성과는 `/dashboard#growth`에서 캠페인·날짜·채널별 증분으로 기록한다. 근거 메모에 게시 URL, 집계 기간과 확인 시각, 플랫폼에 표시된 지표명, 고유 링크·전환 확인 방법을 적는다. 수입은 실제 AdSense/제휴 정산 화면 또는 협찬 계약·이행·정산 자료와 대조하고, 비용은 영수증·결제내역으로 증빙한다. 개인별 비공개 트래픽·수익·계정 ID·정산 원문은 공개 문서에 넣지 않고 `artifacts/operations/`의 비공개 근거로 보관한다. 미조회·미승인·미정산은 0으로 바꾸지 말고 `미확인` 또는 `추정`으로 구분한다.
