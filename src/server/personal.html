등록한 웹사이트

내 웹사이트를 열기까지

주소를 이미 가지고 있다면 도메인 연결 단계부터 보세요. 사이트를 준비 중이라면 이름만 먼저 등록하고 나중에 주소를 붙일 수 있어요.

  1. 가비아에서 도메인 구매

    원하는 이름을 .com, .kr 등으로 검색하고 등록 가능 여부를 확인하세요. 첫해 할인과 연장 가격, 등록 기간, 부가세를 포함한 결제 금액을 비교하세요.

    계속 사용할 본인 계정과 복구 이메일로 등록하세요. 등록이 끝나면 내 웹사이트에 등록 업체와 만료일을 적어두세요.

    가비아 도메인 검색
  2. 호스팅을 정하고 먼저 미리보기 열기

    개발한 사이트라면 GitHub의 본인 저장소를 Vercel에서 가져오고, 테스트용 브랜치의 Preview 주소로 PC와 모바일 화면을 먼저 열어보세요. 제작 서비스에서 만든 사이트라면 해당 서비스의 도메인 연결 메뉴를 사용하세요.

    로그인이나 개인 데이터가 있다면 테스트 계정으로 확인하세요. Supabase를 사용하는 경우 RLS를 켜고 계정 두 개로 서로의 데이터가 조회되지 않는지 확인하세요. 키는 호스팅 서비스의 비밀 설정에 보관하세요.

    GitHub와 Vercel 연결 Supabase RLS
  3. 도메인 연결과 HTTPS 확인

    Vercel이라면 프로젝트의 Domains에 도메인을 추가하세요. 가비아 네임서버를 사용하면 My가비아 → 서비스 관리 → DNS 관리툴의 해당 도메인에서 호스팅 화면이 안내하는 레코드를 입력하세요. 다른 네임서버를 쓰면 그 운영 서비스에서 설정하세요.

    바꾸기 전에 기존 레코드를 백업하고, 호스팅 화면이 표시한 이름과 값을 복사하세요. 이메일의 MX·SPF·DKIM과 기존 서비스의 레코드는 유지하세요. 대표 주소와 www 주소를 쓸 경우 각각 열어 이동과 HTTPS를 확인하세요.

    내 웹사이트의 DNS 확인에서 A·AAAA·CNAME 응답 여부를 볼 수 있어요. 공개 화면과 HTTPS 상태는 브라우저로 직접 열어 확인하세요.

    Vercel 도메인 연결 안내 가비아 DNS 설정 안내
  4. 공개하고 갱신과 장애에 대비하기

    미리보기에서 링크, 로그인, 문의를 확인하고 문제가 없으면 운영 브랜치로 반영하세요. 실제 주소에서 같은 흐름을 다시 열어보고, 문제가 생겼을 때 돌아갈 배포를 알아두세요.

    검색에 노출할 공개 사이트라면 Search Console에서 도메인 속성을 추가하고 안내받은 DNS 레코드로 소유권을 확인하세요. 도메인 만료일, 호스팅 결제일, 복구 수단, 백업 위치를 정리하고 갱신을 미리 확인하세요.

    Search Console 소유권 확인
